# Buscador API (Consulta APIs Brasil Pro)

Um sistema profissional e organizado para selecionar APIs, preparar consultas e ler ou exportar respostas de maneira eficiente e intuitiva. 

## 🎯 Objetivo do Projeto

Fornecer uma interface clara e sóbria para o uso interno (com futura abertura para usuários externos), focada na legibilidade, facilidade de consulta e leitura de resultados de diversas APIs. O design prioriza a consistência de navegação, mantendo uma identidade visual profissional e preparada para diferentes tamanhos de tela.

## ✨ Principais Funcionalidades

- **Seleção de APIs**: Escolha fácil entre as APIs disponíveis.
- **Preparação de Consultas**: Interface dedicada para inserir os parâmetros necessários.
- **Leitura de Respostas**: Visualização clara e organizada dos dados retornados.
- **Acessibilidade**: Foco visível, navegação por teclado e contraste adequado para uso diário.
- **Responsividade**: Interface que se adapta a diferentes dispositivos.

## 🚀 Como Executar o Projeto

### Pré-requisitos
Certifique-se de ter o [Node.js](https://nodejs.org/) instalado na sua máquina.

### Instalação

1. Clone este repositório:
   ```bash
   git clone https://github.com/Ronickbr/buscadorAPI.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd buscadorAPI
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```

### Scripts Disponíveis

- **Iniciar Servidor Backend:**
  ```bash
  npm start
  ```
  *(Inicia o servidor utilizando o arquivo `server/start.js`)*

- **Executar Front-end em Desenvolvimento (Vite):**
  ```bash
  npm run dev
  ```

- **Build para Produção:**
  ```bash
  npm run build
  ```

- **Visualizar o Build de Produção:**
  ```bash
  npm run preview
  ```

## 🛠️ Tecnologias e Ferramentas

- **Vite**: Build tool rápido para o front-end.
- **JavaScript (Vanilla/ESModules)**: Lógica principal de consultas e endpoints.
- **Node.js**: Servidor de apoio para gerenciamento e autenticação (backend).
- **HTML/CSS**: Estruturação semântica e estilização customizada profissional.

## 🎨 Princípios de Design
- Priorizar a consulta e a leitura do resultado.
- Manter navegação e ações consistentes.
- Preservar identidade com aplicação discreta, sem excesso de distrações.
- Garantir acessibilidade (contraste legível, foco visível).

## 📄 Notas Adicionais

Este projeto foi desenhado evitando o uso excessivo de elementos visuais distrativos, priorizando a eficiência para o trabalho diário de consultas de APIs.
